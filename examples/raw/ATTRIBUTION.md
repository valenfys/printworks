# Sample file provenance

These RAW files are used to exercise `printworks` end-to-end and to give
new users something to run the examples in the main README against.
All four are dedicated to the public domain
([CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)) by their
original photographers and sourced from
[raw.pixls.us](https://raw.pixls.us/), a community-maintained repository
of camera RAW samples used for testing open-source raw processing
software (darktable, RawTherapee, rawloader, and others).

| File | Camera | Original source |
| --- | --- | --- |
| `canon-rebelxt.CR2` | Canon EOS Digital Rebel XT | <https://raw.pixls.us/getfile.php/1230/nice/> |
| `nikon-d40.NEF` | Nikon D40 | <https://raw.pixls.us/getfile.php/3618/nice/> |
| `panasonic-lx7.RW2` | Panasonic DMC-LX7 | <https://raw.pixls.us/getfile.php/7009/nice/> |
| `sony-a7s.ARW` | Sony ILCE-7S | <https://raw.pixls.us/getfile.php/1582/nice/> |

No changes were made to the files beyond renaming them.
